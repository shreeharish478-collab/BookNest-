# 📚 BookNest

BookNest is a PHP-based online book reading platform designed to provide users with a simple, responsive, and user-friendly reading experience. The platform allows users to browse books, manage their personal library, explore categories, read reviews, and access various reading-related features through an intuitive interface.

## 🚀 Features

### User Features

* User Registration and Login System
* Secure Authentication
* Browse Books by Categories
* My Books Collection
* Book Reviews and Ratings
* Search and Discover Books
* Responsive Design for Mobile and Desktop
* Dark Mode and Light Mode Support
* Subscription Information Page
* Contact and Support Page

### Interface Features

* Modern and Responsive UI
* Clean Navigation
* Mobile-Friendly Layout
* User-Friendly Reading Experience
* Automatic Theme Adaptation

### Additional Features

* Basic AI Chatbot for User Assistance
* Terms and Conditions Page
* License Information Page
* About Us Section

## ⚙️ Installation

### Requirements

* PHP 8.0 or higher
* MySQL
* Apache Server (XAMPP/WAMP/Laragon)

### Setup Steps

1. Clone the repository:booknest
   git clone https://github.com/yourusername/BookNest.git

3. Move the project folder into your web server directory.

4. Create a MySQL database.

5. Import the provided SQL file into the database.

6. Configure database credentials in the PHP configuration file.

7. Start Apache and MySQL services.

8. Open your browser and visit:
   http://localhost/BookNest
